# @slopstack/ui

Optional customizable shadcn-based controls and Slopstack presentation patterns. Components are available from `@slopstack/ui/components/ui/<name>` and patterns from `@slopstack/ui/patterns/<name>`. Import `@slopstack/ui/styles.css` for theme tokens and override them in the consuming app.

Install with `npm install @slopstack/ui react react-dom`. Tailwind 4 is an optional peer for utility class generation; Vite plugin setup and component customization remain app-owned.
