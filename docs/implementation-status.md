## Known issues and remaining work

The deterministic course generator creates a short fixture lesson rather than a model-generated curriculum; it uses selected learner notes, while the live provider path plans an outline and generates lessons in two stages from selected owner-checked sources/concepts and profile context. The Audio Studio creates and validates source-grounded scripts in two provider stages and supports turn-level Piper playback, but does not persist assembled audio or distinct host voices. Language speaking practice uses Piper/Whisper with transcript-only English word matching; it does not evaluate pronunciation quality. There is no verified live LLM or speech integration or learner-history personalization. Captions use the saved profile default and timestamped segments when provided. Narration prepares an in-memory timeline on first playback; the learner profile stores the selected advertised Piper voice and speaker, but audio assets are not persisted. Progress evidence is recorded per scene. Assessments currently support multiple choice, multiple select, true/false, numeric tolerance, exact short text/fill-in answers, normalized formula text, ordering, and matching. Rubric-based AI grading, diagram/widget/code/grammar/listening/spoken questions, mastery-based difficulty calibration, and prerequisite-driven remediation remain incomplete. Adaptive practice currently covers deterministic definition-recall quizzes from selected, due, weak, or mixed knowledge units. Offline assessments queue sanitized questions and answer submissions locally; final grading and evidence creation require an online authenticated sync. Production deployments still need a configured AI provider and Wyoming speech services. Robust scene schema validation, full podcast production, offline narration/media downloads, and broader end-to-end verification remain outstanding. The complete specification is not complete.
