# @slopstack/react

React session/state stores, hooks, route and layout composition for Slopstack. React 18 or newer is a peer dependency. The `./query` entry point uses an app-provided TanStack React Query 5 installation. `./forms` is an optional form entry point that also needs `@slopstack/ui`.

Install with `npm install @slopstack/react react`. See `docs/frontend-packages.md` for package boundaries and upgrade guidance.
