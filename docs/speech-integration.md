# Speech integration

Piper and Whisper are optional external Wyoming TCP services. Set `STARBURST_WYOMING_PIPER_HOST`/`PORT` and `STARBURST_WYOMING_WHISPER_HOST`/`PORT` in the server environment. The backend implements `describe`, Piper `synthesize`, and Whisper `transcribe` over Wyoming TCP; Piper audio chunks are assembled as WAV. Whisper uploads currently accept PCM 16-bit mono/stereo WAV from 8–96 kHz, capped at 20 MiB, and send the raw PCM samples to the Wyoming service. The browser calls authenticated Starburst API endpoints and never connects to Wyoming directly. The app provides a Piper connection check/voice preview, WAV transcription upload, and grammar answer submission from WAV uploads. Audio is streamed through the request and is not persisted. Protocol fixture tests pass, but no live speech service is configured, so live discovery, synthesis, and transcription remain unverified. Audio Studio synthesizes podcast turns through the same endpoint and can play them sequentially when Piper is configured and reachable. Language speaking practice captures mono PCM WAV in the browser or accepts a WAV upload, sends it to Whisper, and compares the transcript to an owned English vocabulary word. The feedback is transcript-based and does not claim to score pronunciation or accent. Both speaker roles use Piper’s configured default voice; generated episode audio is not persisted. Voice discovery UI, audio persistence/caching, media normalization for WebM/other formats, and lesson narration selection remain unimplemented.
