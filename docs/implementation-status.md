## Known issues and remaining work

The deterministic course generator creates a short fixture lesson rather than a model-generated curriculum; it uses selected learner notes, while the live provider path plans an outline and generates lessons in two stages from selected owner-checked sources/concepts and profile context. The Audio Studio creates and validates source-grounded scripts in two provider stages, supports owner-scoped host/guest voices and turn playback, targets due-review concepts with saved snapshots, and stores a complete generated WAV on each episode. Language speaking practice uses Piper/Whisper with transcript-only English word matching; it does not evaluate pronunciation quality. There is no verified live LLM or speech integration or learner-history personalization. Captions use the saved profile default and timestamped segments when provided. Narration prepares a timeline on first playback using server-cached per-scene WAVs keyed by course version, text, voice, and speaker; offline copies remain explicit downloads. Cache entries are removed when a course is deleted, but no eviction policy exists for older versions. Progress evidence is recorded per scene. Assessments currently support multiple choice, multiple select, true/false, numeric tolerance, exact short text/fill-in answers, normalized formula text, ordering, matching, grammar transformation, and listening comprehension. Rubric-based AI grading, diagram/widget/code/spoken questions, and deeper prerequisite-driven curriculum adaptation remain incomplete. Adaptive practice covers deterministic recognition and reverse-recall quizzes from selected, due, weak, gap, mixed, course, and module sources; gap quizzes traverse weak concepts' prerequisites up to three levels. Offline assessments queue sanitized questions and answer submissions locally; final grading and evidence creation require an online authenticated sync. Listening prompts use Piper online and an installed browser speech voice offline. Production deployments still need a configured AI provider and Wyoming speech services. Broader offline media downloads and broader end-to-end verification remain outstanding. The complete specification is not complete.
