# @slopstack/pocketbase

Optional adapters for PocketBase resource CRUD, authentication, and realtime cache invalidation. PocketBase is a peer dependency for the PocketBase-backed entry points. The `./realtime` entry point additionally uses app-provided React and TanStack Query.

Install with `npm install @slopstack/pocketbase pocketbase` only in apps that choose PocketBase. See `docs/frontend-packages.md` for the generic REST path.
